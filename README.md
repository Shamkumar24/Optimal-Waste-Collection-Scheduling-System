# Optimal Waste Collection Scheduling System

A Java Swing based desktop application developed to improve waste collection scheduling in urban areas.

---

## 📌 Project Description
The Optimal Waste Collection Scheduling System helps in organizing waste collection efficiently by assigning priority based on garbage levels. Workers can update garbage levels, and drivers can mark areas as collected using a centralized dashboard.

---

## 🚀 Features
- User Registration and Login
- Java Swing based Desktop Interface
- Garbage Level Update (Low / Medium / High)
- Priority-based Waste Collection
- Centralized Dashboard
- Mark Area as Collected

---

## 🛠 Technologies Used

- Java Swing
- MySQL
- JDBC
- Event Handling
